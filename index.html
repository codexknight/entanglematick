Core Features

Master & Slave Account Selection

Select any connected account as Master. Individually check multiple Slave accounts to receive copied trades.

Initial Order Replication

New Master orders (Limit, Stop, etc.) are automatically copied to selected Slaves.

Quantity Ratio per Slave

Assign a unique quantity Ratio to each Slave.

Paired Trading Mode (Optional)

Master Fills trigger new Market Orders on Slaves.

Pair Configuration per Slave

When Paired Mode is ON: Specify the exact Instrument for each Slave. Choose if the Slave order direction is Same (↑↑) or Opposite (↑↓) to the Master fill.

Order Modification Sync

Changes to Master order Limit Price or Stop Price automatically update corresponding working Slave orders.

Order Cancellation Sync

Cancelling a working Master order automatically sends cancellation requests for corresponding Slave orders.

Dynamic UI

Slave list updates dynamically. Pair controls enable/disable with Pair Mode. Visual indicators for Master & Pair status.

Session-Based Configuration

Settings are configured manually each session and *not* saved between restarts. Ensures a clean setup every time, preventing accidental trades from old settings.

Robust Internal Handling

Uses thread-safe mechanisms and internal cleanup logic for stability and efficient order tracking.

In Summary

Entanglematick provides a flexible solution for traders needing to copy trades differentially across accounts, allowing variations in quantity, instrument (via pairing), and direction for sophisticated multi-account strategies within NinjaTrader.
